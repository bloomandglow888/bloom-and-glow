# Весна внутри — Тайный сад, версия 3

Откройте `index.html` в Chrome на телефоне. Интернет не нужен для сада и дневника, но нужен для перехода в Telegram.

## Новое
- Рыжая кошка моргает, шевелит хвостом, реагирует на касание и говорит короткие фразы в зависимости от времени суток.
- Раздел «Помоги саду стать лучше»: ошибки и предложения, открывает @Bloomandglow_bot с маркером типа обращения.
- Личные записи и настроение не отправляются боту.

## Важно для запуска
- Это **прототип**. Кнопки обратной связи открывают бота, но **не пересылают** сообщения владельцу автоматически. Нужно отдельно настроить обработку команд `/start feedback_bug` и `/start feedback_idea`, сбор пользовательских сообщений и доставку в приватный администраторский чат.
- Не публикуйте бот-токен в HTML или GitHub. Обработчик должен работать на сервере.
- Дневник хранится в localStorage, не шифруется, может быть прочитан на разблокированном устройстве и исчезнуть при очистке браузера.
- При открытии новой версии в другом расположении локальный прогресс может не перенестись.
